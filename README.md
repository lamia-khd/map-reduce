# MapReduce TP 2 - HDFS & Hadoop

Projet Hadoop MapReduce (TP2 Big Data).

## Contenu
- `src/main/java/hadoop/mapreduce/tp2/PaymentJob.java` : Job MapReduce (Mapper, Combiner, Reducer) pour compter le nombre de transactions par mode de paiement.
- `src/main/resources/input/mini.txt` : Jeu de test local avec cas d'erreurs/lignes mal formées.
- `start_hadoop_cluster.bat` : Script automatisé pour lancer le cluster Hadoop et tester le job.
- `rapport_partie_b_q4.txt` : Rapport détaillé pour la Question 4 de la Partie B.
- `rapport_exercice1.txt` : Réponses complètes aux 4 questions de l'Exercice 1.
